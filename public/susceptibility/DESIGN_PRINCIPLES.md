# 网页设计原则清单

供审阅与后续修改使用。每一条都应能在页面上逐项核对。

## 一、论证与结构
1. 章节顺序固定：动机 → 推导 → 实验 → 应用 → 讨论；每一块都服务于“世界知识带来先发优势，幻觉限制边际收益；固定 LLM 的响应率不超过固定策略，嵌套共同缩放才能越过”这一主张。
2. 思维从上到下流动：任何结论出现之前，其依据已经出现；任何概念（响应率 χ、传递系数 α、响应曲面 J(t, i)、嵌套）在使用前已定义，且全文用同一名称、同一符号。
3. 不放与论证无关的类比、术语或数据（例：已删去的“系综平均 ↔ 种子平均”“无源/有源元件”）；读者会问“为什么在这里”的内容一律删去或降为小字。
4. 讨论中的思维链实验只展示非推理模型。
5. 未开源的优化器只讲原理与实验结果，不涉及实现细节。

## 二、发布会原则
6. 简洁：只放关键思想与关键实验，次要证据降为说明文字或删去。
7. 用最漂亮、最直观的方式表达；情感大于数据：标题落在观点上，用正式、凝练的书面语，不口语、不堆术语。
8. 能用图表达的不用字；宣传图（首屏）表达意义远大于精确意义，一维示意、字越少越好。
9. 每张图的标题即结论，两秒内读懂；数字与注意事项放在灰色小字说明里，不用醒目的提示框。

## 三、图表
10. 指标方向“越大越好”：例如用“每百万 token 合格题数”，而不用“每题消耗 token”。
11. 比较须在同一条件下进行：例如在同一轮次比较不同工具数，而不是比较各自的终点。
12. 颜色只编码固定含义：蓝 = 固定策略 / 基线，金 = LLM / 优化器；不为装饰引入额外颜色（如棕、红高亮柱）；需要强调最大值时用一条参考线。
13. 一个曲面一次只展示一个模型，并写明定义；柱状图与曲面相互衔接（柱状图是曲面在某一轮次的切片）。
14. 所有数据图由真实记录在页面中绘制（data.js），不嵌入位图；示意图明确标注为示意。

## 四、交互与动画
15. 动画控件沿用 Detailed Balance 的形式：标签 + 金色读数（如“轮次 20 / 60”）、滑块、主按钮“播放 ↗︎ / 暂停”、次按钮“重置”；由用户点击开始，不自动播放。
16. 需要表达过程的地方用动画（同轮次工具比较、自我演化的流向）；尊重“减少动态效果”的系统设置。

## 五、工程
17. 中英文成对、一一对应；手机宽度下无横向滚动；中文在 canvas 与等宽字体中均有回退字体。
