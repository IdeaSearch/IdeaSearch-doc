A linear-response lens on LLM agents

世界知识带来先发优势，
幻觉限制边际收益。

World knowledge confers a head start;
hallucination bounds the marginal return.

预算越大、问题越复杂，固定的 LLM 越落后于固定策略：每多一份预算，它换来的收益更少。

The larger the budget and the more complex the problem, the further a fixed LLM falls behind a fixed strategy: each extra unit of budget buys it less.

01 / MOTIVATION

将 LLM 视为
线性响应的黑箱。

Treat the LLM as
a linear-response black box.

LLM 有数千亿参数，内部动力学无从逐一追踪。统计物理面对复杂系统，不求解微观细节，只施加小扰动、测量宏观响应。我们对 LLM 采取同样的立场。

An LLM has hundreds of billions of parameters; its internal dynamics cannot be traced one by one. Statistical physics does not solve the microscopic details of a complex system. It applies a small perturbation and measures how a macroscopic quantity responds. We take the same stance toward the LLM.

03 / TRANSFER传递系数Transfer coefficientχ′ = α · χ

固定 LLM 串入流水线，把固定策略的响应率 χ 变为 χ′

A fixed LLM inserted in the pipeline turns the base response χ into χ′

只测响应、不问机制：经过固定 LLM 后，响应率会变大还是变小？

Measure only the response, not the mechanism: does a fixed LLM raise or lower the susceptibility?

02 / DERIVATION

知识的增益终会耗尽，
幻觉的损耗不会。

Knowledge gains run out;
hallucination costs do not.

固定策略在预算 ℬ 下给出策略集 Pℬ；固定 LLM 读入后改写为 P′ℬ。改写的效果有两面。

A fixed strategy gives a strategy set Pℬ at budget ℬ; a fixed LLM reads it and rewrites it as P′ℬ. The rewrite cuts both ways.

A

世界知识：粗糙基线上的增益

World knowledge: gains on a rough baseline

基线离最优尚远时，LLM 的事实与常识足以纠错，衍生策略领先。

While the baseline is far from optimal, the facts and common sense the LLM holds can correct it, and the derived strategy leads.

B

幻觉：近优基线上的损耗

Hallucination: losses on a near-optimal baseline

基线接近最优后，改进空间收窄，LLM 的改动更可能引入错误。

Once the baseline is near optimal, the room for improvement shrinks and the LLM's changes are more likely to add errors.

LLM 参数固定，其信息贡献不随预算增长；固定策略却随预算不断逼近最优。

With fixed parameters, the LLM's information does not grow with budget, while the fixed strategy keeps closing in on the optimum.

α = χ′ / χ ≤ 1

预算足够大时，经过固定 LLM 的响应率 χ′ 不超过固定策略的 χ。

At large budget, the susceptibility χ′ through a fixed LLM does not exceed the fixed strategy's χ.

上界只约束参数固定的 LLM；让 LLM 随预算一同扩大，才能越过它。

The bound constrains only a fixed-parameter LLM. Letting the LLM itself grow with the budget is the way past it.

信息论视角An information-theoretic view

参数固定的 LLM 可视为容量有限的信道。由数据处理不等式，衍生集与最优策略的互信息不超过基础集与最优策略的互信息。该论证给出动机，并非证明；“足够大”的位置由实验确定。

A fixed LLM acts as a channel of finite capacity. By the data-processing inequality, the derived set carries no more mutual information with the optimum than the base set. This motivates the bound but does not prove it; where “sufficiently large” begins is set by experiment.

03 / EXPERIMENTS

领先归零，
落后扩大。

The lead vanishes.
The deficit grows.

上界给出两条可检验的预言：LLM 的领先随预算消失、落后随预算扩大；任何固定配置的 α 都不超过 1。

The bound makes two testable predictions: the LLM's lead converges and its deficit widens with budget; no fixed configuration has α significantly above 1.

LLM curves average several models.

预言二 · 固定配置无一越过上界Prediction II · no fixed configuration crosses the bound

对每个固定配置，取 LLM 与固定策略的斜率之比 α。

For each fixed configuration, take the ratio α of the LLM slope to the fixed-strategy slope.

04 / APPLICATIONS

上界划出禁区，
也指明出路。

The bound marks a dead end
and points the way out.

在经过固定 LLM 的通道上追加预算，收益追不上固定策略。值得投入的有两处：让 LLM 随预算一同扩大，或投向边际响应仍为正的通道。

Extra budget on a channel through a fixed LLM cannot catch the fixed strategy. Two places are worth the budget: let the LLM grow with it, or spend on channels whose marginal response is still positive.

01
NESTED ARCHITECTURE

嵌套：选择器与生成器一同扩大Nesting: let the selector grow with the generator

一种常见的回答问题方法是先生成多个选项，然后从中选择最好的一个。保持选择器不变，逐步提升生成器的能力，就能考察更强的生成器对最终答案正确率的影响；此时固定选择器仍受响应率上界约束。如果让选择器与生成器使用同一个模型、一起变大，选择器本身就随预算增长，上界不再适用。

A common way to answer a question is to generate several candidate answers, then select the best one. Keeping the selector fixed while increasing the capability of the generator shows how a stronger generator affects the accuracy of the final answer. The fixed selector still obeys the susceptibility bound. If the selector and generator use the same model and grow together, the selector itself grows with the budget, so the bound no longer applies.

02
TOOLS AND TURNS · PRBENCH DMRG

工具并非越多越好More tools is not better

在一个真实的 agent 任务中，agent 面对二维的选择：用多少工具，交互多少轮。在这个二维空间中，响应率决定了任务得分随着选择变化的整体规律。

In a real agent task, the agent must choose along two dimensions: how many tools to use and how many turns to take. In this two-dimensional space, susceptibility determines the overall pattern of how the task score changes with these choices.

要紧的不是最优点落在何处，而是曲面的形状：每条预算通道的边际响应终将趋零或转负，且仅凭黑箱观测即可测得。

What matters is not where the sweet spot sits but the shape of the surface: every channel's marginal response eventually flattens or turns negative, and this is measurable from black-box observations alone.

03
ONLINE BUDGET ALLOCATION

把预算投向仍有响应的地方Spend where the response is still positive

示意

Schematic

为此，可以设计一个外置优化器。优化器在运行中做同一件事：以各轨迹的检查点在线估计响应曲面及其不确定度，把后续预算投向边际响应最高处，响应已趋零的方向不再投入。它只读取黑箱观测。

For this purpose, we can design an external optimizer. The optimizer does the same thing while it runs: from the checkpoints of all trajectories it estimates the response surface and its uncertainty online, sends further budget where the marginal response is highest, and none where it has flattened. It reads only black-box observables.

05 / DISCUSSION

同一条上界，
照见思维链、多模态与自我演化。

One bound, seen in chains of thought,
multimodality and self-evolution.

三个延伸：以零响应率为基线时的上界，多个异质通道同时经过 LLM 时的例外，以及对自我演化的含义。

Three extensions: the form of the bound against a zero-susceptibility baseline, its limits when several heterogeneous channels pass through the LLM, and what it implies for self-evolution.

01
NON-REASONING MODELS · ZERO BASELINE

思维链越长，正确率越低Longer chains, lower accuracy

每一步续写都是固定 LLM 作用于已有生成；对照是原样返回输入、响应率为零的处理器。上界因此预言：链足够长后，正确率随链长下降。

Each continuation step is a fixed LLM acting on the generation so far; the reference is a processor that returns its input, with zero susceptibility. The bound therefore predicts that accuracy falls with chain length once chains are long enough.

02
CONJECTURE · HETEROGENEOUS CHANNELS

代码无从结合的信号，LLM 可以融合Signals code cannot combine, an LLM can

以上实验每次只改变一个通道。多个通道同时经过 LLM 时，每个通道各自有损、各受上界约束。

The experiments above vary one channel at a time. When several channels pass through the LLM together, each is lossy and bounded on its own.

示意

Schematic

信号异质时，比较随之改变：多模态观测须合并为一次推断时，常规代码往往无从结合，只能利用其中一路。

The comparison changes when signals are heterogeneous. When multimodal observations must be combined into one physical or engineering inference, conventional code may have no way to combine them, so its response to the joint signal comes only from the channel it can process.

此时 LLM 虽逐通道有损，仍能利用代码无法利用的信息；在极端或开放环境中，agent 可能胜过代码。

A lossy LLM can then still use information the code cannot; in extreme or open-ended environments, the agent may outperform the code.

03
SELF-EVOLUTION

嵌套越过上界时，能力自我加速Past the bound, capability accelerates itself

假设能力为 b 的模型生成训练数据，其质量为 p(b)；用这批数据训练后，模型的输出质量 l 升至数据的水平，能力随之更新，如此往复。p 与 l 谁增长更快，决定这条阶梯的去向。

Assume that a model of capability b generates training data of quality p(b); after training on it, the model's output quality l rises to match the data, and its capability moves to a new b. Then it repeats. Whether p or l rises faster decides where the staircase goes.

p(b)：生成数据的质量p(b): quality of generated datal(b)：模型输出的质量l(b): quality of the model's output迭代：生成 ↑，训练 →iteration: generate ↑, train →

固定的 LLM 追不上固定策略的斜率；
唯有随预算一同成长，才能越过这条线。

A fixed LLM cannot escape the slope of a fixed strategy; only by growing with the budget can it cross the line.
