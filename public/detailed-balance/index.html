02 / THEORY

方向由终点组织，
再让低概率边显现。

后训练按终点重排转移的倾向，通向同一状态的各条路径因此朝同一方向倾斜。再为每条转移加入微弱返回，正逆概率的强弱比就成为有效描述的入口。Post-training reorders transition tendencies by their destination, so every path into the same state tilts the same way. Add a weak return to every transition, and the forward–reverse ratio becomes the entry point for an effective description.

A

假设 A：方向只看终点，与路径无关

美丽的贝加尔湖有许多儿子，
却只有一个女儿。

——俄罗斯传说 贝加尔湖与安加拉河

后训练重排的是状态之间转移的倾向，奖励 RRR 刻画这种重排。常见的奖励只取决于转移落在哪里：多步推导与一步到位，只要到达同一个正确答案，得到的奖励相同。于是通向 ggg 的每条路径都朝同一个方向倾斜，方向由终点决定。Post-training reorders the tendencies of transitions between states, and the reward RRR describes this reordering. Common rewards depend only on where a transition lands: a multi-step and a one-step derivation of the same correct answer earn the same reward. Every path towards ggg then tilts the same way, and the destination sets the direction.

R(g←f)≈u(g)R(g\leftarrow f) \approx u(g)R(g←f)≈u(g)
B

假设 B：每条路径都带着概率返回边

我们所有探索的终点，
将是回到出发的地方。

——艾略特《四个四重奏 · 小吉丁》

语言模型按概率采样：主导方向之外，返回转移的概率小而非零。采样与语义的不确定性为每条主导转移配上一条微弱回边；在这项假设下，正逆概率比由有效势差组织。An LLM samples from a probability distribution: beyond the dominant direction, a return transition has a small but nonzero probability. Sampling and semantic uncertainty give every dominant transition a weak return edge; under this assumption, forward–reverse ratios are organized by effective potential differences.

THE BOUNDARY

同一祖先经不同路径抵达同一后继时，方向是否只由终点决定，可以直接检验：When the same ancestor reaches the same successor by different paths, whether the destination alone sets the direction can be tested directly: log⁡(P+/P−)=0,\log(P_+/P_-) = 0,log(P+​/P−​)=0,就是待检验的零假设，其中正向一周的概率乘积为 P+P_+P+​，逆向为 P−P_-P−​。即：这些环上的正逆概率比，能否仍由同一个势能统一描述？is the null hypothesis to test. The forward cycle has probability product P+P_+P+​ and the reverse cycle P−P_-P−​. Can the forward–reverse ratio around these cycles still be unified by one potential?
